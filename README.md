# UAP Analysis Platform (frontend)

Este repo contiene el frontend (Vite + React + Tailwind) para la UAP Analysis Platform.

Requisitos:
- Node 18+ recomendado
- npm o yarn

Instalación y desarrollo:
```bash
# en la raíz del repo
npm install

# dev
npm run dev

# build
npm run build

# preview
npm run preview
```

Notas:
- El código fuente está en client/src.
- Alias TS y Vite: `@` apunta a `client/src`.
- Asegúrate de crear/editar la parte servidor (uploads, análisis, DB) según el plan.
